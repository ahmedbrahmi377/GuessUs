# GuessUs
### بناء APK بدون Android Studio
1. أنشئ Repository جديد في GitHub.
2. ارفع **كل محتويات هذا المجلد**، بما فيها `.github`.
3. افتح Actions → Build GuessUs APK.
4. اضغط Run workflow.
5. بعد نجاح البناء افتح Artifacts.
6. نزّل `GuessUs-debug-apk` واستخرج `app-debug.apk`.

ملاحظة: هذه النسخة Prototype محلية. Online الحقيقي وFirebase/Chat اللحظي يحتاجان تنفيذ Backend إضافي.
